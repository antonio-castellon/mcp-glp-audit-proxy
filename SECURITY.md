# Security

Never paste tokens or keys into an issue, a comment, or a commit. If a token has leaked, revoke it at its source.

Report a vulnerability privately, on the Security tab of this repository (Advisories), not in an open issue. Say the version and the client. Do not include secrets.

## What an advisory contains

An advisory names the affected versions, the effect on the integrity of logs that already exist, a workaround or the function to disable, and the fixed version. Fixes are announced in the CHANGELOG. Re-run the OQ after upgrading.
